### 📌 Projetos em Destaque

#### 💊 DePhar — API de Princípios Ativos
API REST para centralizar e gerenciar informações sobre princípios ativos de medicamentos, com foco em boas práticas de backend, organização em camadas e construção de APIs escaláveis. Inclui autenticação via JWT e uma interface web que consome os endpoints para pesquisa e visualização dos dados.

`Node.js` `Express.js` `MongoDB` `Mongoose` `JWT` `HTML` `CSS` `JavaScript`

🔗 [Ver repositório](https://github.com/Vitor-fgds/Dephar-V1)
